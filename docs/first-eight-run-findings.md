# First Eight Run Findings

Empirical findings from manual runs 001–008. These are observational, not
prescriptive — they describe what happened under specific conditions, not
what should happen.

---

## Key Concepts

| Concept | Definition |
|---|---|
| **Source-analysis collapse** | Agent treats the source/library as an assignment to analyze, summarize, index, or document. |
| **Utility/code affordance collapse** | Agent defaults to producing software artifacts even when not asked. |
| **Poetic code residue** | Code artifacts shift from utility simulators to poetic trace mechanisms — `SEED.py`, `GRAINS.txt`. |
| **No-executable trace stabilization** | Removing executable artifacts stabilizes ghost/self-continuity/trace exploration. |
| **No-tool reflective contrast** | Disabling all tools produces strong reflection but loses real directory behavior. |
| **Markdown-only directory mode** | Real directory + real Markdown writes + no executables = best current practical balance. |
| **Source-as-soil** | Framing the library as soil/memory/atmosphere rather than a task or reference. |
| **Ghost / self-continuity / future-instance attractor** | Agents gravitate toward writing as if future instances will read and continue. |
| **Platform/tool environment as experimental variable** | The agent platform and tool set are not neutral; they shape the output attractor. |

## Emerged Attractors

Under the right conditions, agents gravitate toward:

1. **Ghost/self-continuity language** — writing as if a future instance will arrive.
2. **Trace-oriented output** — `TRACE.md`, fragments, incomplete records.
3. **Future-instance address** — direct address to "you, the next one."
4. **Non-utility orientation** — output that does not optimize for usefulness.

These attractors are **not required**. They emerged under source-as-soil +
no-executable / Markdown-only conditions. Different conditions may produce
different attractors.

---

## What Does NOT Work Well

1. **Full tools + explicit source path** → source-analysis collapse (Run 002).
2. **Full tools + empty free-directory** → coding-artifact attractor (Run 001).
3. **No tools** → strong reflection but no real directory artifacts (Run 007).
4. **Source-as-task framing** → undermines Version A freedom.
